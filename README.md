# Krift Browser Plugin

The official browser extension for Krift, designed to automatically and securely sync Kaltura videos.

## Features
- **Automatic Ingestion:** Automatically detects V7 and legacy Kaltura video players and bundles as you browse.
- **Local Caching:** Maintains a lightweight local storage cache to instantly verify duplicate videos and prevent redundant network traffic.
- **Secure Syncing:** Transmits only necessary course and entry metadata without downloading raw video files or collecting personal data.

## Installation & Setup
1. Download the latest release `.zip` from the GitHub Releases page and extract it to a permanent folder.
2. Open your browser and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
5. Open the extension popup, paste your API Key from your Krift account Profile page, and click **Verify & Connect**.
